# Neural Network Thingy
**An entry for 51th GM48 game jam - A Neural Network library.**

This is not meant to be "proper" library you would want to use, it was just something I had fun writing during the jam.

https://gm48.net/game-jams/there-are-ten/games/neural-network-thingy


## So why I made this?
So during GM48 I really didn't come up with any good game idea with theme "there are ten", so I decided to write own neural network library during the jam.

Full of bugs, and barely working to do XOR demo 😂 BUT, it uses GPU (surfaces and fragment shaders), technically supports multi-dimensional tensors with arbitrary dimension count, and it also has rudamentary auto-differentation system for computing gradients.

Also as Shady was not allowed in the jam, I went and wrote own shader preprocessor, in GML. Yeah, you can edit GameMaker projects with GameMaker game, neat.

Also recorded whole thing, 13 GB of videos me talking and coding the thing, mumbling why I can't understand the permutations and indexing. 

[Video of me rambling about the making the library during the jam](https://www.youtube.com/watch?v=Jff18i6RiDE&t=605s)
